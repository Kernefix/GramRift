## О проекте

GramRift — независимый Android-проект KERNEFIX LABS, предназначенный для восстановления соединения Telegram при сетевых ограничениях. В основе — локальное прокси-подключение без аренды удалённых серверов.

### Цели проекта

- Подключение Telegram одним нажатием.
- Локальный прокси без root и системного VPN.
- Фоновая работа и автоматическое восстановление.
- Диагностика соединения.
- Отсутствие рекламы, платных подписок и телеметрии GramRift.

Эффективность зависит от конкретных сетевых ограничений и провайдера. Работа во всех сетях не гарантируется.

## Исходный код и лицензии

Этот репозиторий предназначен для распространения готовых версий приложения и обратной связи. Исходный код GramRift не публикуется.

Сторонние компоненты сохраняют свои оригинальные лицензии. Планируемое сетевое ядро основано на [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (MIT). Уведомления об авторских правах и лицензии используемых компонентов будут включены в дистрибутив.

GramRift не является официальным продуктом Telegram и не связан с его разработчиками.
